# ScoutIQ — Roadmap

## Phase 1: Data Foundation (Week 1)
- Set up project structure and environment
- Connect to football-data.org, confirm fixtures/results pull works
- Connect to API-Football, confirm player stats pull works within rate limit
- Store both in local database

## Phase 2: Core Logic (Week 2)
- Build player comparison logic (side-by-side metrics)
- Build weekly summary logic (top performers, trends)
- Test logic against real data from at least 2 past match weeks

## Phase 3: Dashboard (Week 3)
- Build Streamlit dashboard: standings, comparison tool, weekly summary
- Deploy to Streamlit Community Cloud
- Confirm public link works and loads correctly

## Phase 4: First Public Output (Week 4)
- Generate first weekly summary from live current data
- Publish first post (dashboard link + summary) to chosen platform
  (Twitter/X, Instagram, or newsletter)
- Collect feedback, note what needs fixing

## Phase 5: Consistency Check (Weeks 5-8)
- Publish weekly, same day each week
- Track: did the pipeline run without manual fixes each week
- Track: is anyone engaging with the content (likes, comments, shares)

## Decision Point (End of Week 8)
- If engagement is growing: consider Phase 6 below
- If engagement is flat: keep it as a portfolio piece, reduce time investment

## Phase 6 (Future, not committed yet)
- Add a second league
- Explore monetization (sponsorship, premium insights)
- Explore turning it into a fantasy-football decision tool
